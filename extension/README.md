# Manelly Click'n'Load

Browser-Erweiterung für Chrome und Edge: Klicks auf «Click'n'Load» gehen an Manelly statt an einen JDownloader auf
diesem Rechner. Manelly gibt die Links an den JDownloader auf dem Jellyfin-Server weiter.

Am einfachsten in Manelly unter **Server → JDownloader → Zahnrad → Click'n'Load** «Erweiterung herunterladen» – die ZIP
kennt die Adresse von Manelly schon. Installation siehe README von Manelly.
